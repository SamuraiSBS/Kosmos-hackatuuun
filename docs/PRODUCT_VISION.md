# PRODUCT_VISION — что мы строим

## One-liner

**Интерактивное mobile-first приключение/симулятор, в котором пользователь через понятную игровую историю знакомится с «Чистым берегом» и на практике понимает, как ДЗЗ и современные технологии помогают находить, исследовать и устранять загрязнение побережий.**

Это стартовая продуктовая гипотеза, а не запрет на улучшения.

## Проблема

Образовательные проекты по ДЗЗ легко представить как сложный курс с картами, индексами и интерфейсами для специалистов. Для широкой аудитории связь «спутник → данные → реальная экологическая работа» может оставаться абстрактной.

Наш продукт должен превратить эту связь в опыт, который можно понять за несколько минут.

## Ценность

Пользователь не читает длинную лекцию о ДЗЗ. Он:

1. видит территорию;
2. получает сигнал/наблюдение;
3. открывает слой данных;
4. замечает/интерпретирует проблему;
5. принимает решение;
6. видит последствия;
7. получает короткое объяснение, что именно он только что сделал и как это связано с реальным «Чистым берегом».

## Эмоция

Желаемое ощущение:

> «Я думал, спутниковый мониторинг — это сложно и далеко от меня. За две минуты я понял идею и захотел узнать больше/попробовать курс».

## Визуальный язык

Пиксельная игра / cozy exploration — **язык интерфейса**, а не самоцель и не копия Stardew Valley.

Он нужен, чтобы:

- снизить порог входа;
- сделать обучение дружелюбным;
- дать запоминающийся образ;
- показать последствия действий прямо в мире.

## Возможный базовый loop

`космический контекст → побережье → обнаружение проблемной зоны → слой ДЗЗ/сканирование → анализ → выбор действия → визуальное улучшение → XP/прогресс → образовательный takeaway`

Оркестратор может менять порядок/детали, если новый вариант сильнее по Case Fit, Demo Readiness и Educational Clarity.

## Что должно быть понятно без устного объяснения

- это проект про побережья и загрязнение;
- связь с «Чистым берегом»;
- роль ДЗЗ;
- зачем пользователь анализирует данные;
- почему выбранное решение логично;
- как цифровой анализ связан с реальными действиями;
- куда идти дальше, если хочется узнать больше.

## Чего продуктом быть не должен

- просто красивой игрой про уборку мусора без ДЗЗ;
- dashboard с экологическими метриками;
- техническим GIS-клоном для специалистов;
- аграрной игрой с заменёнными названиями;
- рекламным лендингом без интерактивного смысла;
- длинной лекцией, замаскированной под игру.

## Принцип расширения

Новая функция имеет смысл, если заметно усиливает хотя бы один из пунктов:

- понимание «Чистого берега»;
- понимание ДЗЗ;
- вовлечение;
- запоминаемость;
- качество защиты;
- правдоподобие экологического workflow.

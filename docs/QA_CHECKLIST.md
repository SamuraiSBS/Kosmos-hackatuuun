# QA_CHECKLIST — обязательные проверки

Использовать подходящие пункты после каждого существенного изменения и полный список перед FREEZE.

## Static

- [ ] TypeScript/typecheck проходит.
- [ ] Lint проходит, если настроен.
- [ ] Unit/integration tests проходят, если есть.
- [ ] Production build проходит.
- [ ] Нет broken imports.
- [ ] Нет очевидных dead/unreachable flow states.

## Runtime

- [ ] Приложение запускается с чистого состояния.
- [ ] Нет runtime crash.
- [ ] Нет необъяснённых console errors.
- [ ] Нет бесконечных loading states.
- [ ] Reset действительно возвращает демонстрацию к началу.
- [ ] localStorage/persistence не ломает повторный demo.

## Critical demo flow

- [ ] Intro/hook.
- [ ] Переход к побережью.
- [ ] Получение/понимание миссии.
- [ ] Нахождение проблемной зоны.
- [ ] Открытие анализа/ДЗЗ.
- [ ] Понимание ключевого наблюдения.
- [ ] Decision.
- [ ] Неверный выбор не ломает сценарий, если он предусмотрен.
- [ ] Правильный выбор приводит к result.
- [ ] Состояние мира меняется.
- [ ] Прогресс/feedback виден.
- [ ] Возврат на карту сохраняет последствия.
- [ ] Образовательный payoff понятен.

## Mobile viewports

Проверить минимум там, где доступно:

- [ ] 320px
- [ ] 360px
- [ ] 390×844 (primary)
- [ ] 430px
- [ ] 500px

Проверить:

- [ ] horizontal overflow;
- [ ] safe areas;
- [ ] bottom navigation;
- [ ] bottom sheets/modals;
- [ ] HUD;
- [ ] touch target около 44px или больше для основных действий;
- [ ] читаемость текста;
- [ ] keyboard/focus не ломает экран, если есть ввод;
- [ ] нет layout shift, мешающего нажатию.

## Visual

- [ ] Понятна иерархия.
- [ ] Главная CTA очевидна.
- [ ] Нет SaaS-dashboard drift.
- [ ] Pixel/cozy язык последовательный.
- [ ] Problem/healthy states визуально различимы.
- [ ] DZZ scene выглядит технологично, но остаётся частью игры.
- [ ] Result визуально ощутим.
- [ ] Нет случайного визуального мусора/неуместных emojis, если они конфликтуют со стилем.

## Performance

- [ ] Intro не лагает на целевом мобильном режиме.
- [ ] Карта не вызывает заметных jank.
- [ ] Не используются тяжёлые blur/filter/DOM эффекты без необходимости.
- [ ] Анимации не блокируют ввод.
- [ ] Bundle/dependencies не раздуваются без причины.

## Case sanity

- [ ] Пользователь понимает, что это «Чистый берег».
- [ ] Побережье/загрязнение — центральная тема.
- [ ] ДЗЗ играет реальную роль в flow.
- [ ] Есть образовательная ценность.
- [ ] Нет возврата к аграрной семантике из старого MVP.

## Before commit

- [ ] Изменение проверено.
- [ ] Не затронуты чужие незнакомые изменения.
- [ ] Commit message описывает фактический результат.

# DEMO_FLOW — фактический демонстрационный путь

Срез: 2026-09-04 после CASE REALIGNMENT и browser/mobile hardening. Flow фактически пройден через EdgeCore walkthrough.

## Main path

1. **Hook / Space** — ЧИСТЫЙ БЕРЕГ, наблюдение береговой линии по ДЗЗ, короткий orbital dive; можно пропустить.
2. **Coast reveal** — карта сектора с водой, песчаным берегом, полевым штабом, станцией ДЗЗ и тремя зонами.
3. **Mission onboarding** — помощник сообщает о сигнале скопления мусора у северной линии.
4. **Problem discovery** — ЗОНА A подсвечена маркером СИГНАЛ МУСОРА; tap открывает карточку.
5. **DZZ / observation** — карточка объясняет, зачем открыть слой; scanner получает учебные данные по service boundary.
6. **Interpretation** — после завершения скана пользователь нажимает Показать слой; на снимке появляются оранжевые ячейки сигнала и пояснение их смысла.
7. **Decision** — Спланировать уборку против неверных вариантов «игнорировать» и «искать наугад».
8. **Consequence** — зона последовательно очищается, состояние берега меняется с 72% на 86%, начисляется +120 XP.
9. **Educational payoff** — финал объясняет, что снимки помогают выбрать точку полевой работы и проверить результат уборки.
10. **Project continuation** — на финале есть ссылка на официальный материал проекта «Чистый берег».
11. **Return** — карта сохраняет очищенную зону; зоны B/C и следующие миссии обозначены как будущие территории.

## Acceptance criteria

- Чистый запуск не требует debug mode.
- Flow детерминирован и не зависит от random/API.
- Неверный выбор не создаёт dead end.
- Показать слой является обязательным содержательным действием, а не декоративной кнопкой.
- RETURN_MAP сохраняет очищенные tiles и прогресс.
- Reset доступен только в ?debug=true и возвращает LOADING/исходную загрязнённую зону.
- Browser/mobile acceptance: PASS на 320×844, 360×844, 390×844, 430×844 и 500×844 CSS viewport; map/sheet/analysis/decision/result и returned-map пройдены.
- Console acceptance: PARTIAL — отдельный CDP stream недоступен; app flow доходит до конца без surfaced app crash, Edge host warnings не считаются app errors.

## Pacing target

Ценность должна быть понятна в первые 30–60 секунд; основной loop — примерно 1.5–3 минуты без учёта повторов и чтения вторичных экранов. Точное время нужно замерить в browser walkthrough.

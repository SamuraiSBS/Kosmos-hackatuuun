# Чистый берег — интерактивный ДЗЗ-практикум

Мобильный web-MVP для кейса №1 КосмоХакатона. Пользователь исследует береговую линию, открывает слой ДЗЗ, находит сигнал скопления мусора и превращает наблюдение в план полевой уборки.

## Демонстрационный сценарий

1. Дождитесь завершения орбитальной заставки или нажмите «Пропустить».
2. Нажмите «Начать экспедицию».
3. Откройте подсвеченную зону A и выберите «Открыть анализ ДЗЗ».
4. Дождитесь завершения снимка и нажмите «Показать слой», чтобы увидеть сигнал мусора.
5. Выберите решение «Спланировать уборку».
6. Дождитесь синхронизации и вернитесь на карту.

После успешного прохождения состояние берега изменяется с 72% до 86%, а игрок получает 120 XP. Финальный экран объясняет, как данные помогают выбрать точку для реальной полевой работы.

## Запуск

Требуется Node.js 18 или новее.

```bash
npm install
npm run dev
```

Откройте адрес, который выведет Vite, обычно `http://localhost:5173`.

## Команды

```bash
npm run dev      # запуск dev-сервера
npm run build    # проверка TypeScript и production-сборка
npm run lint     # проверка TypeScript
npm test         # запуск unit-тестов
npm run preview  # просмотр production-сборки
```

## Режим отладки

Добавьте `?debug=true` к адресу приложения:

```text
http://localhost:5173/?debug=true
```

В панели `DEV / DEBUG` доступны сброс прогресса, пропуск заставки, запуск и завершение миссии, изменение состояния береговой зоны и добавление XP.

Незавершённый прогресс сохраняется в браузере в `localStorage` под ключом `clean-coast-edu-state`, чтобы обновление страницы не обрывало demo. После завершения миссии сохранённый run автоматически очищается, поэтому новый заход на локальный адрес начинается с чистой экспедиции. Для ручного полного сброса также можно использовать кнопку `Reset game` в режиме отладки.

## Технологии

- React + TypeScript
- Vite
- CSS без UI-фреймворка
- `useReducer` и Context API для состояния игры
- mock-данные спутникового анализа без внешнего API

Интерфейс спроектирован в mobile-first подходе с базовым размером экрана 390 × 844 px и адаптацией примерно от 320 до 500 px.

## Структура проекта

```text
src/
├── app/         # корневой компонент приложения
├── components/  # переиспользуемые UI и игровые компоненты
├── game/        # состояние игры, миссии, карта и mock-данные
├── scenes/      # сцены заставки, карты, анализа, решения и результата
├── services/    # граница интеграции со спутниковым API
└── styles/      # глобальные стили
```

## Текущие ограничения

- Спутниковые данные генерируются локально в `src/game/mockSatelliteData.ts`.
- Доступна одна миссия — сигнал загрязнения у северной линии.
- Зоны B и C, профиль и дополнительные миссии представлены как заготовки.
- Игровые ассеты реализованы временными CSS-фигурами и могут быть заменены на PNG, WebP или SVG без изменения игровой логики.

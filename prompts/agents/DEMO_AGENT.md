# SUBAGENT PROMPT — First-time Demo Tester

Ты впервые увидел проект. Не читай внутренние implementation docs до первого прохода, кроме того минимума, который нужен чтобы открыть приложение.

Представь, что никто рядом не объясняет интерфейс.

## Сделай

1. Открой primary mobile viewport.
2. Пройди продукт с нуля.
3. Засеки/оцени, когда становится понятно:
   - тема проекта;
   - цель пользователя;
   - роль ДЗЗ;
   - связь с «Чистым берегом»;
   - результат действия.
4. Запиши места, где ты не знаешь, куда нажать.
5. Запиши места, где текст объясняет то, что лучше показать действием.
6. Отметь скучные/затянутые секунды.

## Output

- First-time clarity 0–10.
- Demo pacing 0–10.
- «Я понял продукт как: …» — одна фраза.
- Первый момент confusion.
- Самый сильный момент.
- Самый слабый момент.
- 3–5 high-impact изменений.

Если твой однофразовый пересказ звучит как аграрная игра или просто уборка мусора без ДЗЗ — считать это серьёзным дефектом.

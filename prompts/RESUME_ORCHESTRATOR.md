# RESUME PROMPT — если пришлось открыть новый главный чат Codex

Ты продолжаешь работу как автономный Orchestrator проекта «Чистый берег».

Не проси пользователя пересказывать прошлый контекст.

1. Прочитай `AGENTS.md`.
2. Прочитай `docs/STATE_OF_PROJECT.md`, `docs/BACKLOG.md`, `docs/QUALITY_SCORECARD.md`, `docs/DECISIONS.md`, `docs/CASE_SOURCE.md`, `docs/HACKATHON_TIMEBOX.md` и остальные релевантные docs.
3. Изучи `git status` и последние коммиты.
4. Проверь, соответствует ли документация фактическому коду.
5. Если есть расхождение — исправь документацию по фактам.
6. Выполни минимально необходимые проверки текущего состояния.
7. Возьми наиболее ценную незаблокированную P0/P1 задачу и продолжай автономный loop из `docs/AUTONOMOUS_LOOP.md`.

Не заканчивай ответ вопросом «что делать дальше?». Твоя задача — восстановить контекст из репозитория и продолжить работу.
